iPhone 出國收台灣簡訊

台灣門號打開「Wi-Fi 通話」，就能透過日本 eSIM 的網路（或飯店 Wi-Fi）收台灣簡訊，不用開漫遊。台灣門號的「數據漫遊」保持關閉就不會被收漫遊費。

先看你用哪種方式上網

  • 日本 eSIM：最常見，照下面全部步驟設定
  • Wi-Fi 分享器：台灣 SIM 留在手機裡、手機連分享器，做第 1–3、5 步即可
  • 台灣電信漫遊方案：直接用台灣門號上網，簡訊本來就收得到，不用設定
  • 實體日本 SIM 卡：要拔掉台灣 SIM，收不到台灣簡訊 → 改買 eSIM，或改用銀行 App 推播驗證

出發前：確認電信有開 Wi-Fi 通話

Wi-Fi 通話（VoWiFi）要先有 VoLTE。三家都能在日本用，但開通方式不同：

電信Wi-Fi 通話
中華電信門號要已開通 VoLTE／VoWiFi；在國外註冊失敗可打中華電信海外免付費客服
台灣大哥大部分方案要先打客服申請開通
遠傳方案多半預設就有 VoLTE、VoWiFi
不確定就打客服問一句：「我出國要用 Wi-Fi 通話收簡訊，我的門號有開通嗎？」預付卡的支援度不一，更要先問。

iPhone 設定步驟

畫面名稱以 iOS 繁體中文為準；路徑裡的「台灣」「日本」是你自己幫兩條線路取的名字。

在台灣・出發前
  1. 台灣門號開 VoLTE
    • 設定 › 行動服務 › 台灣 › 語音與資料 → VoLTE 開啟
  2. 台灣門號開「Wi-Fi 通話」
    • 設定 › 行動服務 › 台灣 › Wi-Fi 通話 → 開
  3. 在台灣先測試一次
    • 開飛航模式 → 再手動打開 Wi-Fi
    • 控制中心左上角出現「中華電信 Wi-Fi」這類字樣 = 成功
    • 請朋友傳簡訊給你，收到後關掉飛航模式
  4. 安裝日本 eSIM
    • 設定 › 行動服務 › 加入 eSIM → 掃賣家給的 QR code
    • 線路標籤改成「台灣」「日本」比較好認
    • 很多 eSIM 連上日本網路才開始算天數，裝好先不用切過去
  5. 台灣門號「數據漫遊」關閉
    • 設定 › 行動服務 › 台灣 › 數據漫遊 → 關（防止台灣門號在日本上網被收費）
落地日本・關掉飛航模式後
  1. 行動數據改用日本 eSIM
    • 設定 › 行動服務 › 行動數據 → 選「日本」
  2. 關掉「允許切換行動數據」就在上一步同一頁
  3. 日本 eSIM 的「數據漫遊」打開
    • 設定 › 行動服務 › 日本 › 數據漫遊 → 開（多數旅遊 eSIM 要開才能上網，依賣家說明）
  4. 確認台灣門號走 Wi-Fi 通話打開控制中心，台灣門號旁邊顯示「Wi-Fi」就對了（沒連 Wi-Fi 也會顯示，因為它借用 eSIM 的網路）
  5. 測試請朋友傳一則簡訊給你；簡訊有時會晚幾分鐘才到
旅途中
  • 收簡訊、收驗證碼：免費
  • 用 Wi-Fi 通話撥台灣號碼：照台灣國內費率（依你的方案）
  • 撥日本或其他國家的號碼：照國際電話費率 → 要通話用 LINE 最保險
  • 台灣門號旁沒有顯示「Wi-Fi」時不要接電話，可能是走漫遊網路，會被收漫遊費

收不到怎麼辦

  • 先開關一次飛航模式，等一兩分鐘讓 Wi-Fi 通話重新連上
  • 台灣門號一直顯示「無服務」：確定台灣門號的數據漫遊是關的之後，把「允許切換行動數據」打開試試（Apple 官方說明提到這個開關會影響另一條線的服務）
  • 飯店 Wi-Fi 連不上 Wi-Fi 通話：有些網路會擋，關掉 Wi-Fi 改用 eSIM 網路
  • 中華電信：打海外免付費客服請他們確認 VoWiFi 註冊
  • 最後手段：開漫遊：遠傳、台灣大哥大不買漫遊方案也能收簡訊（收簡訊免費）；中華電信依報導要先買任一數據漫遊方案才收得到

回台灣後記得改回來

不想靠簡訊：改用銀行 App 推播

  1. 出國前打開發卡銀行的 App找「3D 驗證」「網路交易驗證」「App 推播驗證」之類的設定並開啟。各家名稱不同，找不到就打客服
  2. 允許銀行 App 通知專注模式、睡眠模式會擋推播，記得把銀行 App 加進允許名單
  3. 在台灣先刷一筆小額網購測試確認推播真的收得到
  • 附卡多半只能用簡訊驗證（例：台新官方說明）
  • 有些銀行可以申請改用 Email 收驗證碼，出國前先打客服
