日本退稅新制攻略

這趟的免稅購物全部適用新制：結帳先付含稅價，11/9 在那霸機場過海關確認後才退錢。

¥5,000同店同日
未稅滿額才能退
10%消費稅（食品 8%）
扣手續費後退回
90 天購買後
90 天內出境
準備清單該用哪個 App購物時機場退款方式CVV 疑慮踩雷

新制差在哪

  • 舊制結帳直接免稅 → 新制先付全額，出境確認後才退
  • 取消消耗品 ¥50 萬上限，也不再用密封袋
  • 商品仍要原封帶出日本，在日本拆開、吃掉、用掉就不能退
  • 錢由店家／退稅公司退，不是海關給

出發前準備清單

  1. 出發前設定 › 行動服務 › 台灣門號：Wi-Fi 通話 開、數據漫遊 關
  2. 落地後設定 › 行動服務 › 行動數據：選日本 eSIM，「允許切換行動數據」關
  3. 確認控制中心裡台灣門號旁出現「Wi-Fi」就收得到
  4. 回台後行動數據切回台灣門號，關掉日本 eSIM

收簡訊免費，台灣門號別接電話。Wi-Fi 通話要電信開通，台灣大哥大部分方案要先打客服申請；出發前在台灣開飛航模式＋Wi-Fi，請朋友傳簡訊測一次。

先下載哪一個？看店家

每家店配合的退稅系統不同，以收據上的 QR code 為準。四大系統涵蓋台灣旅客大部分的購物：

退稅系統常見店家在台灣能先做
JPrefundSmart DetaxAEON Mall、PARCO、HANDS、3COINS、COSMOS 藥妝、BOOKOFF全部：帳號、護照驗證、綁卡
J-TaxRefundJ&J Tax Free唐吉訶德、BicCamera、鶴羽藥妝、多慶屋、松本清只能記網址：要在日本買過東西才能完成註冊
Global Blue大型百貨（高島屋、大丸松坂屋）、友都八喜帳號、綁卡（不用 CVV）
PIE VAT三井 Outlet Park、LaLaport、澀谷 109、Montbell帳號、綁卡；收據要掃進 App

這趟建議這樣做

  1. 出發前：註冊 JPrefund（jprefund.com）
    • Email 註冊 → 收驗證信
    • 護照驗證：掃護照＋拍一張本人照片
    • 姓名、護照號碼要和護照完全一樣
    • 填地址、電話（國家選 TAIWAN）→ 綁退款卡（要收簡訊驗證碼）
  2. 有逛唐吉訶德、藥妝再用 J-TaxRefund（j-taxrefund.com）
    • 買完再登錄就好，購物後 180 天內都能辦，回台灣再弄也來得及
    • 只想在機場領現金：不用註冊，機場刷護照即可
  3. Global Blue、PIE VAT：這趟沒排百貨、Outlet，用到再裝App 從收據 QR code 或官網連結下載，避免裝到假 App
AEON Mall 用 JPrefund 是依報導整理；同一個商場裡不同店家可能用不同系統，結帳時看收據最準。

1購物時

  1. 結帳出示護照，付含稅全額同一家店、同一天，未稅合計滿 ¥5,000 才能退
  2. 看收據上的退稅 QR code 是哪一家J-TaxRefund、Global Blue、JPrefund、PIE VAT…每家店配合的不同，掃 QR 開對應網站或 App
  3. 註冊帳號、登錄退款方式
    • 拍護照＋拍上陸許可貼紙（入境時貼在護照上）
    • 填英文地址 → 綁卡，或選機場領現金
    • 有的要臉部掃描，整套可能 10–30 分鐘 → 不用在店裡當場弄，回渡假村連 Wi-Fi 再慢慢弄
    • J-TaxRefund 帳號 ID 是系統給的亂碼，截圖記下來
  4. 商品不拆封、收據收好海關以「整張收據」查驗，少一件可能整張都不退

211/9 那霸機場出境

順序最重要：先做海關確認，再託運行李。先託運就拿不出商品給海關看，整筆可能退不了。
  1. 比平常多留 30 分鐘到機場13:35 班機的 4 人時間最趕
  2. 國際線航廈 3F 出境大廳，託運前做海關確認（二選一）
    • 免稅手續 KIOSK：放上護照掃描，幾秒出結果
    • 手機線上：連海關專用 Wi-Fi → 開 Visit Japan Web 確認（要先登錄上陸許可貼紙）
  3. 看結果
    • 綠燈完成 → 直接去託運
    • 紅燈帶全部免稅品＋收據到海關櫃台給人工查驗
  4. 要領現金的人確認完成後，到退稅公司的自助退稅機掃護照領錢（約 1% 手續費）。KIOSK 本身只做確認，不會吐錢
  5. 託運行李、出境化妝水等 100ml 以上液體不能帶上機，確認完記得放進託運箱

3退款方式怎麼選

退到信用卡最方便
  • 確認後幾天到幾週入帳（Global Blue 約 3–5 天）
  • 多數平台綁卡要填 CVV
機場領現金最安心
  • 不用綁卡，那霸機場可領
  • 約 1% 手續費
  • PIE VAT 沒有現金選項
銀行帳戶不建議
  • 小額退款會被跨國匯費吃掉

綁卡要填 CVV 安全碼？

新制上路後有網友在 Threads 貼出綁卡畫面要求填 CVV，引起資安討論。旅日作家林氏璧 11/3 檢視四大系統：

退稅系統綁卡要填 CVV
Global Blue不用
J-TaxRefund要
JPrefund要（已新增機場領現金）
PIE VAT要（沒有現金選項、不能解綁）

自保做法（網友／達人建議）

  • 一張卡綁到底：用額度低、平常少用的卡專門收退款，各平台都綁同一張，資料只外流一次
  • 綁完鎖卡：綁好後在銀行 App 關掉這張卡的海外／網路刷卡
  • 退完解綁：入帳後解除綁定（PIE VAT 目前只能換卡）
  • 不想綁卡：選機場領現金，多付約 1% 手續費
  • 金額很小：扣掉手續費不划算，直接放棄也是選項

網友實測踩雷

  • 先託運才想到要退稅 → 商品拿不出來，退不了
  • 用 eSIM 卻沒開 Wi-Fi 通話 → 收不到台灣簡訊，綁卡卡關（設定看這）
  • 持卡人英文名和護照拼法不同 → 綁卡失敗
  • 在店裡現場註冊太久 → 有人氣到放棄；先付款，回住處再弄
  • 手續費各店不同：唐吉訶德、BicCamera、多慶屋、鶴羽藥妝 0%，其他最高約 6%
  • 不知道該用哪個 App → 看該店收據或店內告示的 QR code
